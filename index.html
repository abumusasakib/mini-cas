Mathematical Engine Guide

Σ

Symbolic Algebra

The engine uses a Dispatcher Kernel to route operations based on data types. It supports:

  • Implicit Multiplication: Auto-detection of multiplication in terms like 2x or 3(y+1).
  • Complex Numbers: Native support for imaginary units (e.g., 3 + 4i).
  • Simplification: Algebraic reduction of terms (e.g., $x + x + 0$ becomes $2x$).
∫

Symbolic Calculus

Mini CAS performs exact symbolic differentiation using recursive rule application:

  • Power Rule: $\frac{d}{dx} x^n = nx^{n-1}$.
  • Product Rule: $(fg)' = f'g + fg'$.
  • Sum/Diff Rules: Linear application across additive terms.
⊞

Linear Algebra

High-performance matrix decomposition and subspace analysis:

  • Fundamental Subspaces: Basis for nullspace(A), colspace(A), and rowspace(A).
  • Decompositions: $A = LU$ and $A = QR$ factorizations.
  • Eigenvalues: Spectral analysis via iterative QR Algorithm.
↗

Vector Analysis

Advanced vector operations for space transformations and geometry:

  • Norm & Unit: Length calculation with norm(u) and normalization with unit(u).
  • Products: Standard inner dot(u, v) and 3D vector cross(u, v).
  • Angles: Computation of exact radian angles between vectors via angle(u, v).
🤖

Machine Learning Suite

Vectorized mathematical kernels for linear regression, classification, metrics, and scaling:

  • Linear Regression: Solve parameters analytically using the Normal Equation normal_eq(X, y).
  • Gradient Descent: Single step optimization for linear or logistic regression gradient_descent(X, y, w, alpha, type).
  • Metrics & Evaluation: Complete suite including regression_metrics, confusion_matrix, and classification_metrics.
